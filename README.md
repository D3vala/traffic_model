# MMDA Traffic Crash Simulator

A single-page web app that presents the results of `MMDA_Traffic_Simulation.ipynb` — how many MMDA-reported crashes a year to expect on EDSA and C5 under different traffic-volume scenarios, and when and where along those roads they were reported.

Group 9 – AM3 · BACALLA, M.D.P. · CASTILLO, C.R.M. · CUEVA, X.L.A

## Open the app

Double-click **`app/index.html`**. It runs from `file://` with no server and no build step — the data loads through a plain `<script>` tag (`app/data/app-data.js`), because `fetch()` of a local JSON file is blocked on `file://`.

Only external request: Google Fonts (Barlow family). If it fails to load, the fallback stack keeps the page readable.

## Project layout

```
MMDA_Traffic_Simulation.ipynb   the pipeline (single source of truth for every number)
data/                           the four inputs, never written
results/                        generated by the notebook (figures, tables, logs, processed)
scripts/
  export_app_data.py            results/ → app/data/app-data.js + app-data.json (with assertions)
  check_app_data.js             independent consistency checks (sums, reconciliation, schema)
app/
  index.html · styles.css · app.js
  data/app-data.js              loaded by the page · app-data.json same content, for reference
NOTES.md                        design plan, assumptions, deviations, open questions
```

## Regenerate the data

1. Run the notebook end to end: `python -m nbconvert --execute MMDA_Traffic_Simulation.ipynb --output MMDA_Traffic_Simulation_executed.ipynb` (or Runtime → Run all). This rebuilds `results/` and re-runs the 34 validation checks.
2. Export for the app: `python scripts/export_app_data.py` — prints a reconciliation table against the brief's Appendix B and fails loudly if any assertion breaks.
3. Verify: `node scripts/check_app_data.js` — hours must sum to the headline mean, zones must sum to their hour, and the frozen-trend means must match the notebook's tables.

Requires Python with pandas/numpy/statsmodels/matplotlib, and Node (any recent version) for the check script.

## Deploy

The app is static. Publish the **`app/`** folder as-is:

- **GitHub Pages** — push the repo, set Pages source to the `app/` directory (or copy `app/` contents to the branch root).
- **Netlify** — drag the `app/` folder into the dashboard, or set the publish directory to `app/`.

No build command, no dependencies.

## State in the URL

`index.html#s=20&e=1.0&h=7` restores an exact view: `s` = traffic scenario percent (0/10/20/30), `e` = elasticity assumption (0.8/1.0/1.2), `h` = hour of day (omitted = all day). Use **Copy link** in the sticky bar or footer to share the current view.
